## 01 — About

Java backend developer working on distributed systems in the Spring ecosystem.

Most of what I build is about how services behave once there is more than one of
them: event-driven workflows over Kafka, gRPC between services, clean boundaries
that survive being deployed separately. Currently in Jamshoro, Pakistan.

  fetch_data.py does not touch it, and its href values and that link row have to
  be changed together.

  in image context. Glyphs are outlined for the same reason -- a webfont would
